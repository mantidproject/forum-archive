Does anyone know if there is a way to get the moderator temp info for a run? I know for some of the instruments in ISIS there are files that store that information in the cycle directories but not every instrument has this and a lot of the logs are incomplete. Is there maybe a main repository of temperature information for ISIS?

DanielMurphy22 December 9, 2019, 10:01am 2

Within Mantid, on a loaded Workspace, clicking the arrow beside it will reveal some info. Sometimes Temperature info is recorded under “Title”.
For more info, right -click on the workspace and select “Show Sample Logs”. Some Temperature info may be there, and if so click on it and a handy plot may be included (as is the case for EMU00020884 in TrainingCourseData)
