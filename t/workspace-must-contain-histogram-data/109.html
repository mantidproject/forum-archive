AndreiSavici April 14, 2016, 6:21pm 2

Mantid was originally developed for TOF instruments. Certain assumptions were made when ConvertUnits was written, such as the workspace has to be a histogram data. What you probably have is point data. What is the difference? In point data you have a Y value for every X value. In histogram data Mantid stores the bin boundaries. So you have one more X value than the number Y values. You can convert between the two representations using ConvertToHistogram and ConvertToPointData algorithms.
