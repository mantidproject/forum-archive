DanielMurphy22 September 3, 2021, 4:51pm 2

The first thing to try is editing the user properties file:

  • Open the file C:\MantidInstall\bin\Mantid.user.properties in any text editor (such as Notepad).
  • Add these 3 lines to the end of the file.
UpdateInstrumentDefinitions.OnStartup = 0
CheckMantidVersion.OnStartup = 0
usagereports.enabled = 0
  • Save the file and try to open MantidWorkbench again.
  • If Mantid still does not open, then add this fourth line to the file

projectRecovery.enabled=false

  • Again save the file and try to open MantidWorkbench

Tell me if these steps work for you or not. There are plenty more steps we can try!
